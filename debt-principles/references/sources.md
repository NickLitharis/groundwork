# Sources and Scope

This skill was extracted from a local practitioner procedure, not from a book. No book was inspected for it.

## Inspected sources

- `ponytail-debt` (a one-shot report that lists deferral markers in a repository): inspected its description of the marker convention (a comment naming the ceiling and upgrade path), its rule to flag markers that name no trigger, its instruction to skip prose that only mentions the marker word, and its grep-based scan. The scan command and output format are not reproduced here. Source: the skill's `SKILL.md` in the local agent skills directory.

## Book-derived principles

None. The idea of recording a limit with the code it limits is a practitioner convention, not a book principle.

## Limits and dated claims

- The procedure defines the marker convention for one local project. Other projects may use different markers, and the suite does not require one.
- The rules are judgment-based. The procedure gives no measured thresholds for when a ceiling is near.

## Modern application

- Recording ceilings and triggers next to code applies to any language, since it depends on comments, not tooling.
- Treating a crossed ceiling as a defect is this skill's application of the procedure's trigger rule, not a claim from the source.
